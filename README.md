# Huzaifa Waqar Butt — Portfolio

A responsive, accessible personal portfolio focused on artificial intelligence, machine learning, and data science.

## Highlights

- Premium dark/light visual system with responsive navigation
- Data-driven project filtering and scroll-based section navigation
- Education, professional training, experience, projects, skills, and contact sections
- Downloadable résumé and direct LinkedIn/GitHub links
- Static export and automated GitHub Pages deployment
- Accessible keyboard controls and reduced-motion support

## Local development

```bash
npm ci
npm run dev
```

## Validation

```bash
npm run lint
npm run build:github
```

## GitHub Pages

The workflow in `.github/workflows/deploy-pages.yml` builds and deploys the portfolio whenever `main` is updated. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.
